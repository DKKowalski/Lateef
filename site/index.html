Questions

It’s your browser. Still.

Which tabs can it see?

Each client sees the tabs it creates and the ones you explicitly share. A tab ID alone isn’t permission. New tabs open inactive, in the window you paired.

How do I turn it off?

Disconnect in the extension. Revoke pairing in the CLI. Close a session and its agent-created tabs are cleaned up.

Does anything leave my computer?

The bridge runs on your computer. Selected page content and files pass to your AI client and may reach its provider. That distinction matters. Read what is shared.

Can it see the page and use a real mouse?

Not by default. An optional full control version adds screenshots, real mouse and keyboard input, scripts and logs through Chrome’s debugger. You install it separately and switch it on in its popup, and Chrome shows a debugging bar while it is in use. How to set it up.

What do I need to run it?

Chrome, Node.js 22+ and an MCP client. The companion is on npm. The extension is not yet on the Chrome Web Store, so you load it by hand.

What doesn’t work yet?

Uploads are capped at 25 MiB total. Password entry isn’t supported. Canvases and sites that need real key presses need the optional full control version. Attaching a file to a Gmail draft is checked on macOS. Linux and Windows pass the automated tests, but only macOS has had everyday use.
