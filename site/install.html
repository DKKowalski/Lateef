DEVELOPER BETA / LOCAL REVIEW BUILD

A few steps.
A quieter browser.

Requires Node.js 22+, Chrome and an MCP-compatible AI client. This source beta is not on npm or the Chrome Web Store yet.

Download source beta ↗ Extension ZIP npm package (.tgz) SHA256SUMS

Verify downloads from the folder that holds them: shasum -a 256 -c SHA256SUMS

  1. Extract and install the companion. Keep the source directory in place; your MCP config will refer to it.After extracting the source zip, cd into the extracted folder before running npm ci.
    cd /path/to/extracted/source
npm ci
node bin/quiet-chrome.mjs setup
    quiet-chrome is the earlier name of the same command; lateef works once the package is installed.
  2. Load the extension. Open chrome://extensions in the profile you want. Enable Developer mode, choose Load unpacked, and select the extracted extension directory. No store installation is available yet.
  3. Pair your chosen window.
    node bin/quiet-chrome.mjs pair
    Open Lateef’s popup in that existing Chrome window. Enter the displayed port and one-time code. Do not paste the code in chat or public issues.
  4. Connect your AI client. The setup command prints JSON with the correct absolute paths. Copy it into your client’s MCP settings and reconnect the client. For TOML:
    node bin/quiet-chrome.mjs config --toml
  5. Check the connection.
    node bin/quiet-chrome.mjs doctor
    Then ask the client to call browser_status and open a background test tab. Each session sees only its own tabs unless you share an existing tab.

Optional: install the local package

Instead of running from the source folder, you can install the offered package: npm install -g ./lateef-0.2.0-beta.1.tgz. This does not register MCP automatically; still run setup and add the config to your client.

First task to try

Open example.com in a new background tab.
Read its title and introductory text.
Close only the tab you created.

Updating and uninstalling

Close active MCP clients, run node bin/quiet-chrome.mjs stop, update the source and run npm ci. Reload the extension in Chrome and reconnect the client. Existing pairing uses the legacy ~/.config/quiet-chrome directory. Doctor detects older loaded versions. To uninstall, remove the client’s MCP entry, stop the companion, remove the Chrome extension, and delete local state if desired.

Beta limits

Uploads: 1–4 authorized files, 2 MiB total, exact destination origin required. Gmail attachment support is not verified. Iframes, passwords, downloads, canvas-only UIs and trusted hardware events are unsupported. Only macOS has been validated so far. Understand what data is shared.
